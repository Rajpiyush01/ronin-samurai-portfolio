# Ronin Portfolio V2 — Samurai Edition

A redesigned black-and-dark-red portfolio starter for Piyush Raj. This version includes a visible samurai hero illustration (`public/samurai-hero.jpg`), responsive navigation, animated scroll progress, motion-revealed skill cards, and About / Projects / Skills / Journey / Contact sections.

## Run locally
Install Node.js 20.9 or newer, then:
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Customize before publishing
Edit `app/page.tsx`:
- Replace `your.email@example.com` with your email.
- Replace generic GitHub and LinkedIn links with your profiles.
- Replace example projects with real projects and repository/demo links.
- Keep only skills you can confidently explain.

The samurai hero artwork is in `public/samurai-hero.jpg`.
